Bearbeitung von Personendaten

Wir bearbeiten Personendaten, die erforderlich sind, um diese Website bereitzustellen, Anfragen zu beantworten, Buchungen zu ermöglichen und unsere Leistungen anzubieten. Dabei beachten wir das anwendbare Schweizer Datenschutzrecht.

Kontaktaufnahme

Wenn Sie uns per E-Mail oder über das Kontaktformular kontaktieren, bearbeiten wir die von Ihnen übermittelten Angaben, insbesondere Name, E-Mail-Adresse, optional Telefonnummer, ausgewählte Unterkunft und Inhalt Ihrer Nachricht, zur Bearbeitung Ihrer Anfrage und für die weitere Kommunikation.

Für den technischen Versand des Kontaktformulars wird FormSubmit eingesetzt. Die im Formular eingegebenen Daten werden zum Zweck der Übermittlung der Nachricht an diesen Dienst übertragen und anschliessend an unsere Kontaktadresse weitergeleitet.

Buchungssystem Smoobu

Für Verfügbarkeitsprüfung, Preise und Buchungen ist das Buchungssystem Smoobu eingebunden. Wenn Sie den Buchungsbereich nutzen, werden Inhalte des Anbieters geladen. Dabei können technisch notwendige Daten sowie die von Ihnen im Buchungsprozess eingegebenen Angaben durch Smoobu verarbeitet werden. Für Buchungs- und gegebenenfalls Zahlungsvorgänge gelten ergänzend die Datenschutzinformationen und Bedingungen der jeweils eingebundenen Anbieter.

Aufbewahrung

Personendaten werden nur so lange aufbewahrt, wie dies zur Erfüllung des jeweiligen Zwecks erforderlich ist oder gesetzliche Aufbewahrungspflichten bestehen.

Bereitstellung der Website

Beim Aufruf dieser Website können technisch notwendige Daten wie IP-Adresse, Datum und Uhrzeit des Zugriffs, aufgerufene Seiten sowie Angaben zu Browser und Betriebssystem durch den Hosting-Dienst verarbeitet werden. Diese Verarbeitung dient der sicheren und zuverlässigen Bereitstellung der Website.

Externe Dienste und Inhalte

Die Website wird über GitHub Pages bereitgestellt, einen Dienst von GitHub, Inc. Dabei können technisch notwendige Daten durch GitHub verarbeitet und auch ausserhalb der Schweiz bearbeitet werden. Für die Datenbearbeitung durch GitHub gelten die Datenschutzbestimmungen des Anbieters.

Zur Darstellung von Schriftarten nutzt die Website Google Fonts. Beim Laden der Schriftarten kann eine Verbindung zu Servern von Google hergestellt werden, wobei insbesondere die IP-Adresse technisch übermittelt werden kann.

Einzelne Unterkunftsbilder werden über externe Bildserver bereitgestellt. Beim Laden solcher Bilder kann eine Verbindung zum jeweiligen Anbieter hergestellt werden, bei der technisch notwendige Verbindungsdaten übertragen werden.

Tracking und Analyse

Wir setzen auf dieser Website keine eigenen Analyse- oder Trackingdienste wie Google Analytics oder Meta Pixel ein.
